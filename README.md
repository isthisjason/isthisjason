Hi, I'm Jason.

I like building practical software that turns messy real-world workflows into something easier to run, inspect, and improve. Lately that has meant portfolio tooling, local AI utilities, finance dashboards, and applied ML systems with enough structure around them to feel like real products instead of one-off demos.

## What I build

- Personal tools that remove repetitive work from creative, job-search, and portfolio workflows.
- Full-stack apps where the backend, frontend, data model, and deployment story all matter.
- Local-first experiments around AI, automation, and financial data that stay explainable and testable.

## Featured projects

### [SignalAttention](https://github.com/isthisjason/signal-attention)

A local trading research sandbox built around repeatable simulations, risk scoring, paper trading, audit trails, and market-regime analysis. The goal is not to make a trading bot; it is to explore how strategy behavior, candle data, and ML-style analysis can be modeled in a system that is inspectable from API to dashboard.

### [jasonpeng.dev](https://github.com/isthisjason/jasonpeng.dev)

My portfolio site, built as a more intentional home for my projects, experience, and resume context. It uses a custom visual direction and integrates a separate chatbot widget so visitors can ask about my work without the main site owning the chat logic.

### [portfolio-chatbot](https://github.com/isthisjason/portfolio-chatbot)

An embeddable portfolio chatbot with a standalone widget, Cloudflare Worker backend, structured portfolio context, rate-limit controls, and a clean integration contract. I keep it separate from the portfolio so the chat experience can be developed, tested, and deployed independently.

### [CaptionForge UI](https://github.com/isthisjason/captionforge-ui)

A local captioning tool for LoRA dataset prep. It has both a Gradio web UI and CLI, supports BLIP caption generation, trigger words, folder workflows, caption review, and CPU/CUDA device selection.

### [CashFlowGo](https://github.com/isthisjason/cashflowgo)

A full-stack personal finance app with budgeting, transaction tracking, subscription management, profile switching, dashboard charts, CSV export, and an offline-capable frontend fallback for smoother development.

### [Aby](https://github.com/isthisjason/aby)

A TanStack Start app with admin/reviewer roles, application workflows, Cloudflare D1 persistence, R2 image handling, privacy operations, backup/restore scripts, and deployment-focused security notes.

## Current focus

I'm sharpening the parts of software that make projects durable: testing, deployment, data flow, auth boundaries, observability, and clear product workflows. The common thread across my repos is building systems I can explain end to end, then tightening them until they are useful outside the first demo.
